Je planning wordt bewaard in een privé-repository op GitHub. Elk apparaat waar je hetzelfde token invult, werkt bij en leest mee. Zonder internet blijft alles gewoon lokaal werken; zodra je weer online bent, wordt het samengevoegd.

Token maken: GitHub → Settings → Developer settings → Fine-grained tokens → alleen deze repository, rechten Contents: Read and write. Het token blijft op dit apparaat staan en wordt nergens anders heen gestuurd.
